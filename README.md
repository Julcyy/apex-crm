# Apex General CRM (demo)

Single-page mini CRM dashboard for an electrical & HVAC field-services company (simplified ServiceTitan-style).

## Files

- `index.html` — full dashboard (stats, drag-and-drop dispatch board, lead detail + AI Summary, inbox)
- `README.md` — this file

## How to open

1. Open `index.html` in any modern browser (Chrome, Safari, Edge, Firefox).
2. Or from this folder run: `open index.html` (macOS) / double-click the file.

No install, no build step, no server required.

## Try it

- Click a lead card to open the detail panel.
- Click **AI Summary** for a sample issue summary + suggested action.
- Drag cards between **New Leads**, **Assigned**, and **Done**.

## Booking demo

Open `booking.html` in a browser for the multi-step scheduler mock (ZIP → service → date/time → contact → details → local confirmation). Does not call Apex or ServiceTitan.

## Homepage demo

Open `homepage.html` for a local visual recreation of the Apex marketing homepage (demo only; Book Now → `booking.html`).
